## Limits and next work

Human morning acceptance is still needed. Live screen lock/wake, app relaunch during OS lock, true keychain-lock recovery, broader Accessibility app compatibility and multi-hour energy behavior were not exercised. Lock/generation/cancellation safeguards are implemented; automated boundary tests do not prove all OS transitions. Exact windows require reselection after restart. The existing host reports a review-waiting workflow as running with its Review step; completion/failure detection does not invent a more specific phase.

Activity is an in-app timeline/attention status, not new macOS push notifications. Clear context clears the transient buffer; selected enabled sources refresh on the next check. Pause stops collection. It cannot retract text already shared in a conversation.

No Kokoro weights or verified Agent TTS bundle were available in the checked project/cache locations. Neural speech, preset-voice audition, offline packaging and immediate Stop remain the next optional speech milestone; no silent cross-app dependency or hosted TTS fallback was introduced. The wider Voice Parakeet/Canary/Nemotron upgrade remains explicitly deferred. Public distribution/notarization and Laya promotion are not claimed.
