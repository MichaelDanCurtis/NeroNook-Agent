# Nero Agent

Independent NeroNook plugin. Read README.md. Use documented Codex app-server managed ChatGPT authentication. Never copy desktop/browser tokens, inherit the user's Codex integrations, or silently switch to API-key billing. Keep provider runtime configuration and credentials isolated. No microphone/voice work in this milestone.

Agent output is a proposal; only the generic host action service may authorize a module change. No ambient shell, file, browser, computer or connector tools in the conversational runtime. If containment is not demonstrated, keep proposals read-only and record the gap. Keep public distribution and actual account acceptance separate from builds/fixtures. No automatic subagent delegation.
